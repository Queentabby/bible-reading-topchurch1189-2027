# 團隊讀經打卡

一個讓讀經小組每天打卡、互相看到進度的網站。成員只要輸入名稱和密碼就能使用，不需要 Claude 帳號，也不需要 Google 帳號。

整個系統分成兩部分：

- **網站（index.html、config.js）**：放在 GitHub Pages，免費。
- **資料庫（Code.gs）**：放在你的 Google 試算表，所有打卡紀錄、筆記和讀經計畫都存在這份試算表裡。

---

## 第一步：建立 Google 試算表和後端

1. 打開 [Google 試算表](https://sheets.google.com)，建立一份新的空白試算表，命名為「讀經打卡資料」。
2. 點上方選單「擴充功能」→「Apps Script」。
3. 把編輯器裡原本的內容全部刪掉，貼上 `Code.gs` 的完整內容。
4. 找到第 8 行，把 `請改成你們的邀請碼` 改成你們自己的邀請碼，例如 `grace2026`。成員註冊時需要輸入這組邀請碼，請不要用太容易猜到的字。
5. 按「儲存」圖示（或 Ctrl+S）。
6. 在編輯器上方的函式選單選「setup」，按「執行」。
   - 第一次會要求授權：按「審查權限」→ 選你的 Google 帳號 →「進階」→「前往（不安全）」→「允許」。這是 Google 對所有自己寫的程式都會顯示的提醒，程式只會存取這一份試算表。
   - 執行完成後，回到試算表會看到 members、progress、notes、sessions、settings 五個工作表。
7. 點右上角「部署」→「新增部署作業」。
   - 左邊齒輪選「網頁應用程式」。
   - 「執行身分」選「我」。
   - 「誰可以存取」選「所有人」。
   - 按「部署」，複製出現的「網頁應用程式網址」（以 `https://script.google.com/macros/s/` 開頭，`/exec` 結尾）。

## 第二步：把網站放上 GitHub

1. 到 [github.com](https://github.com) 註冊帳號並登入。
2. 右上角「+」→「New repository」。
   - Repository name 填 `bible-reading`（可自訂，會出現在網址裡）。
   - 選「Public」。
   - 按「Create repository」。
3. 在新的頁面點「uploading an existing file」，把 `index.html`、`config.js`、`README.md` 三個檔案拖進去，按「Commit changes」。
   - `Code.gs` 不需要上傳。
4. 在檔案列表點 `config.js` → 右上角鉛筆圖示，把第一步複製的網址貼到 `API_URL: ""` 的引號中間，按「Commit changes」。
5. 點上方「Settings」→ 左側「Pages」。
   - Source 選「Deploy from a branch」。
   - Branch 選「main」、資料夾選「/ (root)」，按「Save」。
6. 等 1～2 分鐘，重新整理頁面，上方會出現網站網址，例如 `https://你的帳號.github.io/bible-reading/`。

## 第三步：開始使用

1. **你要第一個註冊。**打開網站，點「第一次使用」，輸入邀請碼、名稱和密碼。第一位註冊的人會自動成為「建立者」。
2. 到「讀經計畫」確認開始日期與休息日，按「儲存計畫」。
3. 把網站網址和邀請碼傳到 LINE 群組，請大家註冊。建議提醒大家把網站「加入主畫面」，用起來就像 APP。
4. 在「人員管理」可以把同工設為管理員。

## 角色與權限

| 功能 | 建立者 | 管理員 | 一般成員 |
| --- | --- | --- | --- |
| 打卡、寫筆記、看團隊進度 | ✓ | ✓ | ✓ |
| 修改讀經計畫 | ✓ | ✓ | |
| 替成員重設密碼、移出名單 | ✓ | ✓（不能動其他管理員） | |
| 指定或取消管理員 | ✓ | | |

這些權限都由後端檢查，不是只隱藏按鈕。

## 常見問題

**成員忘記密碼怎麼辦？**
由管理員到「人員管理」按「重設密碼」，設定新密碼後告訴對方，對方登入後可以在「團隊進度」最下方自行修改。

**密碼輸錯會怎樣？**
連續輸錯 5 次會鎖定 15 分鐘。

**筆記真的只有自己看得到嗎？**
在網站上，筆記只會傳給本人，其他成員和管理員都看不到。但筆記內容存在 Google 試算表的 notes 工作表裡，試算表的擁有者（也就是你）打開試算表就看得到。請不要把這份試算表分享給其他人，也建議讓成員知道這一點。

**可以直接改試算表的資料嗎？**
不建議。欄位格式被程式依賴，手動修改可能讓網站讀不到資料。如果需要備份，用試算表的「檔案」→「版本記錄」即可。

**修改了 Code.gs 之後網站沒有變化？**
Apps Script 每次修改都要重新發布：「部署」→「管理部署作業」→ 鉛筆圖示 →「版本」選「新版本」→「部署」。這樣網址不會改變，不用更新 config.js。

**有使用量限制嗎？**
Google 免費帳號的 Apps Script 每天有執行時間上限，以 10～30 人的讀經小組每天打卡的用量來說綽綽有餘。
